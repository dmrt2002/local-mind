# Caption vs Summary Analysis

## Investigation Summary

This document explains how captions and summaries are stored and displayed for screenshot snippets.

## Database Schema

**Current Implementation:**
- The database does **NOT** have separate `caption` and `ocr_text` columns in the `snippets` table
- Only `content` and `summary` fields are used

**Storage Structure:**
- `content` field: Stores combined text in format `[Caption: ...] [Text: ...]`
  - `[Caption: ...]` contains the Florence-2 generated caption
  - `[Text: ...]` contains the OCR extracted text
- `summary` field: Stores the intelligent summary generated from caption + OCR text

## Data Flow

1. **Caption Generation** (Florence-2):
   - Generated by `vision::generate_caption()` using Florence-2 model
   - Stored in `content` field as `[Caption: ...]`

2. **OCR Text Extraction**:
   - Extracted by OCR engines (Apple Vision or Tesseract)
   - Stored in `content` field as `[Text: ...]`

3. **Summary Generation**:
   - Generated by LLM or rule-based summarization
   - Takes BOTH caption and OCR text as input
   - Stored in `summary` field
   - This is what's displayed in the UI as the main text

## UI Display

**ScreenshotCard.tsx:**
- Displays `snippet.summary` as the title/description

**ScreenshotLightbox.tsx:**
- Displays `snippet.summary` as the main heading
- Parses `snippet.content` to extract:
  - Caption from `[Caption: ...]` section
  - OCR text from `[Text: ...]` section
- Shows caption and OCR text separately in the sidebar

## Answer to Your Question

**"Gateway detects a workflow failure with unstable workflow runs"**

This text is most likely stored in the **`summary`** field, which means:

1. ✅ It was generated by **LLM or rule-based summarization** (NOT directly by Florence-2)
2. ✅ It was created from BOTH the Florence-2 caption AND the OCR text
3. ✅ It's what you see displayed in the UI as the snippet description

**To verify this in your database:**
- Use the new `search_text_in_database` command with the text
- It will search in `summary`, `content`, and check if separate `caption`/`ocr_text` columns exist

## Conclusion

The text you see in the UI (`snippet.summary`) is **NOT** the raw Florence-2 caption. It's an intelligent summary generated from both the caption and OCR text. The raw caption is stored in the `content` field within the `[Caption: ...]` section, and can be viewed in the screenshot lightbox.
